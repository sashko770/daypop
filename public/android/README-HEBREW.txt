========================================================================
מדריך התקנה לאנדרואיד - DayPop (Android Installation Guide)
========================================================================

ישנן שתי דרכים להתקנת DayPop במכשיר האנדרואיד שלך:

------------------------------------------------------------------------
דרך 1: התקנה ישירה מהירה מהדפדפן (הדרך המומלצת ביותר ע"י Google - WebAPK)
------------------------------------------------------------------------
מערכת Android תומכת באופן מובנה בהתקנת אפליקציות WebAPK ישירות למכשיר!
1. פתח את הדפדפן (Google Chrome או Samsung Internet) במכשיר האנדרואיד שלך.
2. היכנס לכתובת האפליקציה (ניתן לסרוק את קוד ה-QR מהמסך).
3. לחץ על כפתור "התקן אפליקציה לאנדרואיד" שמופיע באפליקציה,
   או לחץ על תפריט שלוש הנקודות (⋮) בפינה העליונה ובחר "התקן אפליקציה" / "הוסף למסך הבית".
4. המערכת תתקין את DayPop כאפליקציית אנדרואיד עצמאית לחלוטין:
   - מופיעה במגירת האפליקציות (App Drawer) ובהגדרות הטלפון
   - עובדת במצב מסך מלא ללא סרגל דפדפן
   - עובדת גם ללא חיבור לאינטרנט (Offline Cache)
   - גישה למיקרופון לעוזר הקולי

------------------------------------------------------------------------
דרך 2: הפקת קובץ APK מלא להתקנה (Sideload / Google Play)
------------------------------------------------------------------------
קבצי החבילה הדרושים נמצאים בתיקייה זו (twa-manifest.json, AndroidManifest.xml).
לבניית קובץ APK חתום:

אפשרות א' - דרך PWABuilder (ללא צורך בהתקנת כלים במחשב):
1. היכנס לאתר: https://www.pwabuilder.com
2. הדבק את כתובת ה-URL של האפליקציה
3. לחץ על "Package for Android" -> בחר "Generate APK"
4. תקבל ישירות קובץ .apk שניתן להעביר ולהתקין בכל טלפון אנדרואיד!

אפשרות ב' - דרך שורת הפקודה (Bubblewrap CLI הרשמי של גוגל):
1. ודא שמותקן אצלך Node.js ו-Android SDK
2. הרץ בטרמינל בתיקייה זו:
   npx @bubblewrap/cli init --manifest=twa-manifest.json
   npx @bubblewrap/cli build
3. יופק קובץ app-release-signed.apk מוכן להתקנה או להעלאה ל-Google Play Store!
